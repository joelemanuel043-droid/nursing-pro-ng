# Nursing Pro NG — PWA starter

Includes a mobile-friendly starter dashboard, subject categories, drug-study checklist, clinical learning checklist, sample CBT quiz, starter tutor interface, app manifest, icon, and service worker.

## Preview
Open `index.html` for a basic preview. Installation and offline caching require the files to be hosted over HTTPS (or localhost).

## Publish and install
Upload the files to a static HTTPS host. Open the published link in Chrome on Android, then use the browser menu and choose **Install app** or **Add to Home screen** if offered.

## Not yet included
The tutor is not connected to a live AI service. The drug checklist is educational only and is not a prescribing tool. Clinical calculations and care decisions must be checked against approved references and local protocols.
